# ScrapeGraphAI

AI-powered web scraping API and open-source Python library. Two SDKs (`scrapegraph-py`, `scrapegraph-js`), a REST API at `v2-api.scrapegraphai.com`, a vendor MCP server, and a CLI. Per-format credit meter (markdown=1, json=5, branding=25). Auth is the custom header `SGAI-APIKEY`, not Bearer.

See [`SKILL.md`](./SKILL.md) for the full body — triggers, anti-patterns, the format-cost table, the cURL/SDK quick starts, and the survival playbook for the three calls you reach for first (markdown dump, JSON extract, screenshot of a JS-heavy page).
